# Headline-to-Bars Freestyle

**Pillar:** 3 — AI Hip-Hop/Influencer Content
**Date:** 2026-10-18
**Status:** Pending (Autosheet append blocked — see note at bottom)

## Hook
"Pick any headline posted today. The flow doesn't get a warning about what's in it."

## Caption
Every freestyle clip so far has found a new way to prove it isn't pre-written — a blind beat pull, a hard countdown clock, a comment-ordered sequence — so this one hands the actual subject matter to strangers instead of just the structure: three real headlines pulled live from today's news, on-screen with timestamps, no editing between picks and verses. The bars have to land on whatever those headlines actually say, not a safe paraphrase of them, which means there's no warming up on a topic chosen in advance. It's the same persona and the same one-take rule as every clip before it, just with the one variable that's always been within our control — the subject — handed over this time too. Screenshot the on-screen timestamps against the real headlines if you want to check nothing was swapped after the fact, then drop a headline from today in the comments for the next one and follow @the_shedstudio to see if it survives the same test.

## Production Notes
Single continuous take, vertical framing, no cutaways — same one-take conceit as every prior Pillar 3 clip. Pull three real, current news headlines at record time and burn their on-screen timestamps into the frame so the "live, unedited" claim is independently checkable. Use the established persona character reference for face/voice consistency with prior Pillar 3 clips. Copyright/likeness guardrail: react to the headlines' subject matter only — no specific existing song, no real public figure's likeness/voice beyond what's incidental to reporting a real headline verbally. Needs synced dialogue throughout, so this needs the audio-native model, not a silent render.

## Model
Kling 3 Omni, `generateSound: true` (per Pillar 3's default — synced vocals/dialogue required).
